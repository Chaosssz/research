Assessment Overview
For this assignment, you're expected to create a research repository that explores programming principles and concepts. Your repository must include:

a collection of your own codes
codes that you've been inspired by or practiced (with comments)
programming principles and concepts that you think are interesting or just don't understand (with commentary and analysis)

Instructions

Find or Use Your Own Code

Search for relevant code or use your own code.

Add Your Software Research and Practice Codes to GitHub

Upload the code you found or created to the “Code” tab of your GitHub repository.

Ensure the code is properly documented with comments.

Organize Your Code

Organize your code into folders for clarity, making it easy to navigate.

Analyze and Comment on the Code Using Software Design Principles

Add meaningful comments within your code explaining how these principles are applied (or how they could be improved).

Write a Readme File

Summarize your comments and analysis in a README.md file.

Clearly explain how the software design principles are demonstrated in your code.

This file should help others understand your thought process and research findings.

Submission

Copy the content of your README file from your GitHub repository into a separate Word document or PDF.

Ensure this document contains the same explanation and analysis of the software design principles and concepts from your README file.

Include the GitHub Link

At the beginning of your Word or PDF document, include the link of your GitHub repository.
